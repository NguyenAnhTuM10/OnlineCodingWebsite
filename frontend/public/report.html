1. GIỚI THIỆU VỀ ĐỀ TÀI

1.1. Lý do chọn đề tài

  • Xu hướng thực tế: Trong thời đại số hóa hiện nay, nhu cầu học lập trình trực tuyến ngày càng tăng cao. Đặc biệt sau đại dịch COVID-19, việc học online đã trở thành xu hướng chủ đạo.
  • Nhu cầu người dùng: Nhiều người muốn học lập trình nhưng gặp khó khăn về thời gian, địa điểm và chi phí. Website học lập trình online giúp giải quyết những vấn đề này.
  • Phù hợp với kiến thức: Đề tài cho phép áp dụng toàn bộ kiến thức đã học về Frontend, Backend, và quản lý cơ sở dữ liệu.

1.2. Mục tiêu của đồ án

  • G1: Xây dựng ứng dụng Web học lập trình online với đầy đủ các chức năng cơ bản như đăng ký khóa học, xem bài giảng, theo dõi tiến độ học tập.
  • G2: Áp dụng kiến thức về Frontend (React.js), Backend (Node.js/Express), và cơ sở dữ liệu (MySQL) để tạo ra một hệ thống hoàn chỉnh.
  • G3: Tạo ra một nền tảng giáo dục trực tuyến thân thiện, dễ sử dụng và có khả năng mở rộng.

1.3. Phạm vi thực hiện

Chức năng được xây dựng:

  • Hệ thống đăng ký/đăng nhập người dùng
  • Quản lý khóa học và bài giảng
  • Theo dõi tiến độ học tập
  • Hệ thống bình luận và đánh giá
  • Giao diện quản trị viên

Đối tượng sử dụng:

  • Học viên muốn học lập trình
  • Giảng viên tạo và quản lý khóa học
  • Quản trị viên hệ thống

Các giới hạn:

  • Chưa tích hợp thanh toán online
  • Chưa có hệ thống AI hỗ trợ học tập
  • Chưa có tính năng livestream

2. PHÂN TÍCH YÊU CẦU

2.1. Yêu cầu chức năng

2.1.1. Quản lý người dùng

  • Đăng ký tài khoản với email và mật khẩu
  • Đăng nhập/đăng xuất hệ thống
  • Quản lý thông tin cá nhân
  • Phân quyền người dùng (học viên, giảng viên, admin)

2.1.2. Quản lý khóa học

  • Hiển thị danh sách các khóa học
  • Xem chi tiết thông tin khóa học
  • Đăng ký học khóa học
  • Theo dõi danh sách khóa học đã đăng ký

2.1.3. Quản lý bài giảng

  • Xem video bài giảng
  • Theo dõi tiến độ học tập từng bài
  • Đánh dấu bài đã hoàn thành
  • Lưu lại vị trí xem video

2.1.4. Hệ thống tương tác

  • Bình luận trong từng bài học
  • Đánh giá và nhận xét khóa học
  • Tìm kiếm khóa học theo từ khóa

2.1.5. Giao diện quản trị

  • Quản lý CRUD khóa học
  • Thống kê số lượng học viên
  • Quản lý bài giảng và video
  • Báo cáo tiến độ học tập

2.2. Yêu cầu phi chức năng

  • Hiệu năng: Website phải tải nhanh, xử lý được 100+ người dùng đồng thời
  • Giao diện: Thiết kế responsive, thân thiện trên mọi thiết bị
  • Bảo mật: Mã hóa mật khẩu, bảo vệ thông tin người dùng
  • Khả năng mở rộng: Kiến trúc cho phép thêm tính năng mới dễ dàng

3. TRIỂN KHAI VÀ CÀI ĐẶT

3.1. Mô tả kiến trúc hệ thống

Hệ thống được thiết kế theo mô hình Client-Server với kiến trúc 3 tầng:

  • Presentation Layer: React.js frontend
  • Business Logic Layer: Node.js/Express.js backend
  • Data Access Layer: MySQL database

3.2. Công nghệ và công cụ sử dụng

Frontend:

  • React.js: Framework chính cho giao diện người dùng
  • Tailwind CSS: Framework CSS cho styling
  • JavaScript ES6+: Ngôn ngữ lập trình
  • Axios: Thư viện gọi API

Backend:

  • Node.js: Runtime environment
  • Express.js: Web framework
  • MySQL: Hệ quản trị cơ sở dữ liệu
  • JWT: JSON Web Token cho xác thực
  • Bcrypt: Mã hóa mật khẩu
  • Multer: Upload file/video

Công cụ khác:

  • Git/GitHub: Quản lý mã nguồn
  • Postman: Test API
  • VS Code: IDE phát triển

3.3. Thiết kế Database (ERD)

Các bảng chính:

Bảng Các trường chính Mô tả
Users user_id, username, email, password_hash, role Lưu thông tin người dùng
Courses course_id, title, description, instructor_id, image_url Thông tin khóa học
Lessons lesson_id, course_id, title, video_url, order_index Bài giảng trong khóa học
Enrollments enrollment_id, user_id, course_id, enrolled_at Đăng ký khóa học
Lesson_Progress progress_id, user_id, lesson_id, completed, watch_time Tiến độ học tập
Comments comment_id, user_id, lesson_id, content Bình luận bài học
Reviews review_id, user_id, course_id, rating, comment Đánh giá khóa học

3.4. Hướng dẫn cài đặt và chạy thử

Yêu cầu hệ thống:

  • Node.js >= 18.0
  • MySQL >= 8.0
  • Git

Các bước cài đặt:

1. Clone project:

git clone [repository-url] cd OnlineCodingWebsite

2. Cài đặt Backend:

cd backend npm install

3. Cấu hình database:

  • Tạo database mới trong MySQL
  • Import file fullstack.sql
  • Cấu hình file .env

4. Chạy Backend:

npm start

5. Cài đặt Frontend:

cd ../frontend npm install npm start

6. Truy cập ứng dụng:

  • Frontend: http://localhost:3000
  • Backend API: http://localhost:5000

4. KẾT QUẢ THỰC HIỆN

4.1. Các chức năng đã hoàn thành

4.1.1. Giao diện người dùng

  • Trang chủ: Hiển thị các khóa học nổi bật, giới thiệu nền tảng
  • Danh sách khóa học: Lọc và tìm kiếm khóa học
  • Chi tiết khóa học: Thông tin chi tiết, danh sách bài học
  • Trang học: Xem video, theo dõi tiến độ
  • Hồ sơ cá nhân: Quản lý thông tin, khóa học đã đăng ký

4.1.2. Hệ thống xác thực

  • Đăng ký tài khoản với validation
  • Đăng nhập/đăng xuất an toàn
  • Bảo vệ route với JWT token

4.1.3. Giao diện quản trị

  • Dashboard thống kê tổng quan
  • Quản lý CRUD khóa học đầy đủ
  • Upload và quản lý video bài giảng
  • Báo cáo tiến độ học tập của học viên

4.2. Đánh giá mức độ hoàn thành

Mục tiêu Điểm Ghi chú
G1 - Xây dựng ứng dụng Web học lập trình 85/100 Đã hoàn thành các chức năng cơ bản
G2 - Áp dụng kiến thức Frontend/Backend 90/100 Sử dụng thành thạo React.js và Node.js
G3 - Tạo nền tảng giáo dục thân thiện 80/100 Giao diện đẹp, cần cải thiện UX

5. KẾT LUẬN VÀ HƯỚNG PHÁT TRIỂN

5.1. Những gì đã đạt được

  • Xây dựng thành công một website học lập trình online hoàn chỉnh
  • Áp dụng được kiến thức về Full-stack development
  • Tạo ra sản phẩm có tính thực tiễn cao
  • Nắm vững quy trình phát triển web từ A-Z

5.2. Khó khăn gặp phải

  • Xử lý video: Upload và streaming video với kích thước lớn
  • Đồng bộ dữ liệu: Theo dõi tiến độ học tập real-time
  • Tối ưu hiệu năng: Tải trang nhanh với nhiều media content
  • Responsive design: Đảm bảo giao diện đẹp trên mọi thiết bị

5.3. Hướng phát triển thêm

Chức năng nâng cao:

  • Tích hợp hệ thống thanh toán online (VNPay, Momo)
  • Thêm tính năng livestream cho bài giảng trực tiếp
  • Xây dựng hệ thống AI chatbot hỗ trợ học tập
  • Tạo forum thảo luận cho học viên

Cải tiến kỹ thuật:

  • Sử dụng CDN để tối ưu tốc độ tải video
  • Implement Progressive Web App (PWA)
  • Thêm unit test và integration test
  • Deploy lên cloud platform (AWS, Google Cloud)
